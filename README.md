# Sonory

Extensible provider-neutral music workbench.

## Try the CLI

```sh
pnpm install
pnpm build
pnpm sonory --help
```

## Accounts

Account metadata and defaults are stored in your OS user configuration directory.
Credentials are stored in the OS credential store. Removing an account deletes its
local credentials without revoking the provider session.
